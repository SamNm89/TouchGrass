# TouchGrass - Desktop Game Launcher

A lightweight, high-performance desktop game launcher built for gamers who value speed and minimalism.

## Overview

TouchGrass is a minimal desktop game launcher designed to get out of your way. Built for a client who needed instant access to their game library without sacrificing system performance or desktop real estate. The result is an invisible, always-available launcher that prioritizes speed and usability.

## Key Features

🚀 **Instant Access** - Global hotkey support for lightning-fast game launching  
🎨 **Smart Library Management** - Auto-extracts game icons from executables and displays them in a clean, dark-themed grid  
👻 **True Invisibility** - Complete system tray integration with optional zero-footprint mode  
⚙️ **Fully Configurable** - Customize hotkeys, startup behavior, and library organization  
🎮 **Zero Gaming Impact** - Minimal memory footprint and no background interference

## Technical Stack

- **Language**: C#
- **Framework**: WPF (Windows Presentation Foundation)
- **Core Capabilities**: Win32 API integration, PE file parsing, global hotkey registration

## Implementation Highlights

- **Icon Extraction Engine** - Automatically extracts and caches game icons from .exe files without manual setup
- **Global Hotkey System** - Lightweight Win32-based hotkey registration for instant access from any application
- **Performant UI** - Virtual grid rendering for smooth scrolling with hundreds of games
- **Settings Persistence** - Comprehensive configuration system for hotkeys, theme, and startup behavior
