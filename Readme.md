Built a lightweight desktop game launcher for a client who needed quick access to their library without desktop clutter. The goal was creating a truly invisible app that wouldn't impact gaming performance.

Developed using C# and WPF with features including:

Auto-extracted game icons from .exe files

Instant launch via customizable global hotkeys

Clean grid-based library UI with dark theme

Complete invisibility option

Implemented icon extraction, hotkey registration and comprehensive settings (hotkey customization, startup behavior).
